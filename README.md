# CNN-for-MNIST-Dataset
A Convolutional Neural Network built with [TensorFlow/PyTorch] to classify handwritten digits from the MNIST dataset. Achieves ~99% test accuracy using convolutional and pooling layers, dropout regularization, and softmax classification.
A Convolutional Neural Network (CNN) trained to recognize handwritten digits (0–9) using the MNIST dataset of 70,000 grayscale images. The model uses stacked convolutional and max-pooling layers for feature extraction, followed by fully connected layers with dropout for regularization, achieving strong accuracy on the test set. Built to demonstrate core deep learning concepts including convolution, pooling, batch normalization, and overfitting prevention
